The build question, answered

Yes — this is very buildable. This prototype is plain HTML, CSS, and JavaScript: no frameworks, no build step, no server. It runs on any phone or laptop browser today.

For the real app, the shortest path is React Native + Expo — one JavaScript codebase that ships to both iOS and Android, and gives you the two things a browser can't: true push notifications for dose reminders, and a lock-screen shortcut to the safety card.
